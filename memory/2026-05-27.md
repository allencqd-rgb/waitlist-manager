### 15:59  -  Bug修复：取第一志愿模式下搜索失效

- **问题：** 勾选「取第一志愿」后，未搜索时筛选正常，但搜索后没有进行第一志愿筛选
- **根因：** `App.jsx` 中 `displayEntries` 的计算逻辑：
  ```js
  const displayEntries = firstChoiceMode ? (firstChoiceEntries || filteredEntries) : filteredEntries;
  ```
  `||` 运算符会把空数组 `[]` 视为 falsy，导致搜索后如果 `firstChoiceEntries` 为空（该搜索条件下没有第一志愿记录），错误地回退到 `filteredEntries`（全部搜索结果），跳过了第一志愿筛选
- **修复：** 将 `||` 改为显式判断，直接使用 `firstChoiceEntries`：
  ```js
  const displayEntries = firstChoiceMode ? firstChoiceEntries : filteredEntries;
  ```
  `firstChoiceEntries` 在开启第一志愿时始终是数组（可为空），不再错误回退
- **验证：** `npm run build` 通过
- **部署：** 已提交并推送到 GitHub，执行 `npm run deploy` 更新 GitHub Pages
- **修复提交：** `fix: 修复取第一志愿模式下搜索失效的问题`

### 16:08  - 逻辑顺序修正：先取第一志愿，再搜索

  3. `filteredEntries` 基于 `baseEntries` 进行搜索过滤
  4. `displayEntries` 直接等于 `filteredEntries`
