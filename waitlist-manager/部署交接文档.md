# 演出候补递补管理系统 - 部署交接文档

## 一、项目概述

**项目名称：** 演出候补递补管理系统  
**项目用途：** 管理演出候补名单，支持拖拽递补操作、批量导入导出、数据统计展示  
**当前版本：** v1.0（纯前端版）  
**代码位置：** 见附件压缩包，或联系我获取最新代码

---

## 二、技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| React | 18 | 前端框架 |
| Vite | 5 | 构建工具 |
| Tailwind CSS | v4 | 样式框架 |
| LocalStorage | - | 当前数据存储方式 |

> ⚠️ **重要说明：** 当前版本为纯前端，数据存储在浏览器 LocalStorage，**每人数据独立，不共享**。如需多人协同，需后续接入后端数据库。

## 四、部署到腾讯云（方案建议）

### 方案一：静态托管（推荐，简单快速）

适用于：单人使用或演示，不需要数据共享。

**方式 A - 腾讯云 COS 静态网站**
1. `npm run build` 生成 `dist/` 目录
2. 登录腾讯云控制台 → 对象存储 COS → 创建存储桶（开启静态网站功能）
3. 将 `dist/` 下所有文件上传到存储桶
4. 配置默认首页为 `index.html`，错误页也指向 `index.html`
5. 绑定自定义域名（可选）

**方式 B - 腾讯云 Webify**
1. 将代码推送到 Git 仓库（工蜂/GitHub）
2. 登录腾讯云 Webify → 新建应用 → 关联仓库
3. 构建命令填 `npm run build`，输出目录填 `dist`
4. 自动部署，每次 push 自动更新

---

### 方案二：服务器部署（适合后续加后端）

适用于：团队多人使用，需要数据共享。

1. 购买腾讯云轻量应用服务器或 CVM
2. 服务器安装 Node.js（建议 v18+）
3. `npm run build` 生成 `dist/`
4. 安装 Nginx，配置静态文件服务，指向 `dist/` 目录
5. （后续）可在此基础上增加 Node.js 后端 API，连接数据库

## 六、注意事项

1. **路由问题：** 当前为单页应用（SPA），刷新页面时需确保 Nginx/COS 配置正确，所有路径都指向 `index.html`
2. **Nginx 配置参考：**
   ```nginx
   location / {
     root /path/to/dist;
     index index.html;
     try_files $uri $uri/ /index.html;
   }
   ```
3. **当前无后端：** 如需要登录、权限控制、数据持久化，需额外开发后端服务
4. **数据备份：** 用户当前通过「导出 CSV」自行备份数据
